# AI 使用留痕

任务书第 7 问要求：**保留全部 AI 指令训练过程，说明组员对 AI 结果的判断依据及矫正过程，并清晰标注 AI 贡献与组员贡献**。

## 记录规则

1. **即时记录**：每次使用 AI 后当天写入 `ai_log/YYYY-MM-DD_主题.md`，不要事后补写（补写会丢失纠错细节）。
2. **一问一条**：记录提问原文（可脱敏）、AI 给出的关键结论/代码/数字。
3. **三态判断**：对每条 AI 输出标注
   - ✅ 采纳：说明为什么可信（复算、与教材一致、量纲检查等）；
   - ⚠️ 修改后采纳：说明改了哪里、为什么；
   - ❌ 否决：说明错在哪里。
4. **数字必须复算**：AI 生成或计算的任何进入报告的数字，由组员用独立途径（Excel、手算、另写脚本）复算一遍，差异记入本文件。
5. **代码署名**：报告附录中，AI 生成的代码段落标注 `[AI]`，组员改写或补写的标注 `[组员]`。

## 文件命名

```
ai_log/
  2026-10-23_项目搭建.md      环境与数据源
  2026-10-25_样本构建.md
  ...
  复核记录.md                 组员逐项复核结论汇总
```

## 模板

```markdown
## 提问 N（时间）
**提问原文**：...

**AI 输出摘要**：...

**判断**：✅ 采纳 / ⚠️ 修改 / ❌ 否决
**依据**：...
**复算/验证**：...
```
