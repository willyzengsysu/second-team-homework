# 数据目录

| 目录 | 内容 | 是否随仓库提供 |
|---|---|---|
| snapshots/ | 名单与历史行业快照、待核实事件表 | 是 |
| interim/ | 股票池、候选、基准、利率、来源哈希与退出报价核查 | 是 |
| processed/ | 最终样本、月度面板、宽表、缺失与退出审计 | 是 |
| raw/ | 网络取得的逐股行情及退出日线缓存 | 否，按需运行 S2 重建 |

数据来自交易所名单、baostock、中证指数和中债接口，用于本课程研究。仓库保留来源和转换记录，不对上游数据另行授予使用权；对外使用时应核对上游来源的使用条件并注明出处。

原始缓存不在 GitHub，因此刚克隆后不能直接从 S3 清洗开始；可从 S4 使用已提交面板复现后续分析，或先完成 S1/S2 再运行 S3。离线核验检查提交的数据和结果，并不验证上游数据本身的准确性。

不要用零收益替代未知缺失。退出清偿/换股与分红算法的待核实状态见报告和审计文件。
