# 高贝塔股票是否获得更高收益？

> 投资学第二次团队作业 —— 基于个股与投资组合的 CAPM 模型实证分析

用 2015–2019 年数据估计个股贝塔、按贝塔分五组，检验 2020–2024 年「贝塔越高，平均超额收益是否越高」，并比较个股与组合两种视角下证券市场线（SML）的差异。

本项目不是要证明 CAPM 成立，而是评估**样本证据对 CAPM 的支持程度**：流程规范、证据透明、解释审慎。

## 快速开始

```bash
# 1. 环境（Python 3.12）
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2. 全流程（抓数约 1 小时，之后各阶段都是秒级）
python scripts/run_all.py

# 3. 数据已抓完时，从清洗开始重跑
python scripts/run_all.py --from s3

# 4. 单元测试（不依赖网络）
python -m unittest discover -s tests -v
```

抓数期间建议**关闭系统代理**（项目已在进程内设置 `NO_PROXY`，双保险）；抓完后可随时打开。

## 数据来源与口径

| 项目 | 来源 | 口径 |
|---|---|---|
| 股票名单 | 上交所 / 深交所官方接口 | 冻结于 2019-12-31，**含此后退市的 237 只**，避免幸存者偏差 |
| 行业分类 | baostock 证监会行业分类 | 门类 + 大类，共 85 类 |
| 个股收益 | akshare `stock_zh_a_hist_tx`（腾讯） | 月度后复权收盘价，含分红再投资 |
| 市场收益 | 中证指数官网 H00985 | **中证全指全收益**指数，含分红再投资 |
| 无风险利率 | akshare `bond_china_yield`（中债） | 1 年期国债到期收益率，月度 = (1+y)^(1/12) − 1 |

样本：200 只股票，估计期内每只至少 48 个有效配对月份，按行业分层随机抽取（固定种子 20261023）。
抽样分两段：基础池 260 只（目标 200 × 1.3）+ 追加池 40 只，用于补足因「估计期不足 48 个月」被剔除的部分。

## 关键处理规则

- **停牌**：整月停牌价格未变，收益记 0 并打 `suspended` 标记（这是经济真实值，不是用 0 填补缺失）；可切换为严格口径做敏感性检验。
- **退市**：退市当月仍计入收益，此后自然退出组合，不做事后剔除。
- **缺失**：不填 0；组合当月只用可得成员求均值（等价于恢复等权）。
- **分组**：按历史贝塔**数值**（非绝对值）排序等分五组，每组约 40 只，检验期内不重新分组。
- **置信区间**：H−L 收益差同时报告 t 分布、Newey–West、分块自助法三种区间，并说明各自假设。

## 复现与一致性

- 每个阶段输出 `*_manifest.json`：git 提交号、配置哈希、依赖版本、关键数字；
- `output/tables/numbers_lock.json` 锁定正文引用的每个数字及其来源文件哈希；
- 所有抓取结果按股票缓存，中断后重跑自动续抓。
