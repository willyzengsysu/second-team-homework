## 停牌与退市处理

- 整月停牌：价格未变，收益记 0 并打 `suspended` 标记（口径：`zero_marked`）；
- 退市：退市当月仍计入收益，此后自然退出组合，未做事后剔除；
- 缺失：不填 0；组合均值只用当月可得成员（等价于恢复等权）。
