# 方法说明（2026-10-28 修订）

## 样本和历史信息

交易所名单的保存快照以 list_date<=2019-12-31、delist_date 为空或晚于冻结日重建候选股票池；上市日期未知的记录不自动通过。仅保留沪深 A 股，明确排除 200/900 开头 B 股。名单历史覆盖可能不完整，保留这一限制。

行业 API 显式请求冻结日期，保留原始 updateDate；代码拒绝无日期或未来日期的行业快照。历史行业用于抽样；之后存续状态仅用于退出审计，不参与分层或合格筛选。基础/追加候选按行业数量比例分配，估计期至少 48 个有效配对月后再按行业分配最终名额。随机种子及来源路径见配置。

## 收益及停牌

主来源统一为 baostock 后复权月线，adjustflag=1。退出月可能是非完整交易月，额外请求退出前两个月的同源后复权日线，验证日/月重叠价格一致后补齐有实际成交的末月报价。日线原始证据及哈希单列，报价补齐不等于核实终止清偿。月收益只从相邻自然月有效价格计算。来源零成交量月不视为有效交易报价；未知缺月保持缺失，缺月后的首个报价月不把累计变动塞入一个月。min_close 阈值实际参与清洗。

后复权用于处理分红送转调整，但项目没有逐次重建现金分红再投资路径；对此保留数据口径限制。停牌必须有可追溯来源，不能由“缺月”或“价格没变”推断。verified_monthly_events.csv 支持有来源的 suspension 与 terminal_return；terminal_return 为相对上月资金的月度总收益，必须核对是否已含报价变动和清偿/换股价值，避免重复计入。

未知尾部保留到正式退出月份并标记审计，不视为可成交退出。退出之后不使用行情。组合主口径每月对可得成员求平均，保存成员数；这是可得样本统计，不是带有未退出头寸和资金账户的完整自融资策略。

## 回归、均值及标准误

股票和市场都扣同月无风险代理后，做含截距 OLS。估计期贝塔定义法在相同配对样本上用样本协方差/市场样本方差核对，n-1 分母相消后恒等。全样本最大误差与三只示例最大误差分别记录。

检验期个股至少 12 个有效配对月，此阈值是项目的估计规则，不是任务书附加筛样条件。达不到阈值只是不进入个股回归图，不从既定组合或估计样本删除。均值与回归使用相同配对观测，并保存该股票对应月份的市场平均超额收益。

Newey-West 带宽为 6。个股若有缺月，statsmodels 对有效观测序列计算 HAC，滞后是有效观测序号，不能严格当作六个连续自然月。组合的完整 60 月结果与个股完整 60 月子样本一起阅读。横截面 HC1 标准误不能解决共同冲击和生成回归量问题，五点 SML 仅作描述性拟合。

## H-L 与 CAPM

先报告逐月最高减最低组收益差的均值与 t、HAC、移动分块自助区间。t 区间依赖近似独立同分布等条件；HAC 带宽 6；bootstrap 块长 3、5000 次，需要近似平稳及合适块长，不能称为无假设方法。

再回归 d(t)=alpha(H-L)+delta(beta)*market_excess(t)+u(t)。平均价差为零与 alpha 为零是不同假设；均值恒等于 alpha 加贝塔差乘市场均值。这是一个价差限制检验，不是 CAPM 全部限制或五个 alpha 的联合检验。算术年化价差为 12×月均差，不作为实际复合策略收益。

## SML 与基准偏差

两图横轴检验期贝塔，纵轴平均超额收益，统一坐标。基准线截距零、斜率为整段市场平均超额收益；不足 60 月个股的均值和该市场均值覆盖期不同，另报完整月子样本对照。经验线拟合残差与基准线偏差 MAE/RMSE 是不同指标。

不能从经验线负截距推断某个组合 alpha 为负，也不能只因斜率倍数大就认定散点离基准线更远。聚合会降低噪声并可能抵消正负定价误差；更高 R² 不等于 CAPM 得到验证。

## 已执行的敏感性

全部保持主样本与历史组别。内部缺月末价延续、尾部延续至退出、退出月全损是明确假设的估值/终止收益情景，不把未知标成已确认停牌。全损情景覆盖未核实的终止收益，对清偿或合并换股可能过度悲观，既不是实际收益也不是完整数学上下界。利率简单折月仍保持原报价日期，不能解决月末/期限错配。

固定正斜率线性 Blume 调整不改变股票排序，对本作业重新分组无作用。优先改进是核实退出现金流与未知月；若改估计窗口，全部数据必须在分组日前可得。
